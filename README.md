# Amazon Sales Data Visualization

## Project Overview

This project performs Data Visualization on the Amazon Sales Dataset using Python. The dataset was cleaned, processed, and analyzed to identify patterns related to product pricing, discounts, customer ratings, and product categories. Various visualizations were created to transform raw data into meaningful business insights.

---

## Tasks Performed

- Data Loading
- Data Exploration
- Data Cleaning
- Missing Value Handling
- Data Type Conversion
- Data Preprocessing
- Product Category Analysis
- Rating Analysis
- Discount Analysis
- Price Analysis
- Correlation Analysis
- Data Visualization

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset Description

The Amazon Sales dataset contains information about various products listed on Amazon, including:

- Product Name
- Category
- Actual Price
- Discounted Price
- Discount Percentage
- Product Rating
- Rating Count

---

## Visualizations Created

- Top 10 Most Reviewed Products
- Product Ratings Distribution
- Top Product Categories
- Discount Percentage Distribution
- Products with Highest Savings
- Correlation Heatmap

---

## Key Findings

- Most products have ratings above 4.0, indicating high customer satisfaction.
- Electronics and accessories are the most common product categories in the dataset.
- Discounts are widely used as a marketing strategy to attract customers.
- Products with a higher number of ratings are generally more popular among customers.
- Products offering higher savings attract greater customer attention.
- Correlation analysis shows a strong relationship between actual price and discounted price.

---

## Conclusion

This project demonstrates how data visualization techniques can transform raw sales data into meaningful insights. Through data cleaning, preprocessing, and visualization, important trends related to pricing, discounts, customer ratings, and product categories were identified. These insights can support better business decisions and improve the understanding of customer preferences.
