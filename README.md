Amazon Sales Data Visualization
Project Overview
This project focuses on analyzing and visualizing Amazon sales data using Python. The dataset contains information about product pricing, discounts, ratings, review counts, and categories. The objective is to transform raw data into meaningful visual insights that help understand customer behavior, product performance, and pricing strategies.
Objectives


Clean and preprocess the Amazon sales dataset.


Convert text-based columns into numerical format for analysis.


Analyze product ratings, reviews, discounts, and pricing patterns.


Create visualizations to identify trends and relationships.


Generate actionable insights through data storytelling.


Tools and Technologies


Python


Pandas


Matplotlib


Seaborn


Jupyter Notebook


Dataset Description
The dataset contains information about Amazon products, including:


Product Name


Category


Actual Price


Discounted Price


Discount Percentage


Product Rating


Rating Count


Product Reviews


Data Preprocessing
The following preprocessing steps were performed:


Removed currency symbols (₹), commas, and percentage signs.


Converted relevant columns into numeric data types.


Handled missing values in the rating_count column using median imputation.


Ensured data consistency and quality for analysis.

Key Insights


Most products have ratings above 4.0, indicating high customer satisfaction.


Electronics and accessories dominate the product categories.


Discounts are widely used as a promotional strategy across products.


Popular products tend to receive a significantly higher number of customer reviews.


Products with higher original prices generally maintain higher discounted prices.


Customer ratings show only a weak relationship with discount percentages, suggesting that product quality has a stronger influence on ratings than discounts.


Conclusion
This project demonstrates the importance of data visualization in understanding large datasets. By analyzing Amazon sales data, meaningful insights were uncovered regarding customer preferences, pricing strategies, discounts, and product popularity. The visualizations effectively transformed raw data into information that can support data-driven decision-making.
